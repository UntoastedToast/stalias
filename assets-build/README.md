# Assets build

stalias serves its CSS and JavaScript from the binary, nothing is loaded from a CDN. The
files live in `../src/web/static` and are compiled in with `include_bytes!` (see `src/web/assets.rs`).

| File in `src/web/static/` | Source |
| --- | --- |
| `app.css` | Generated from `styles.css`: [Tailwind CSS](https://tailwindcss.com) (MIT) with [Basecoat](https://basecoatui.com) (MIT) |
| `basecoat.min.js` | Generated by `build-js.mjs`: Basecoat runtime, select, toast and sidebar scripts (MIT) |
| `htmx.min.js` | [htmx](https://htmx.org) 2.x (0BSD), copied as is |
| `geist-1.7.2.woff2` | [Geist](https://vercel.com/font) Sans (SIL OFL 1.1, license in `geist-OFL.txt`), variable font reduced to Latin |
| `app.js`, `logo.svg` | stalias |

Icons live in `../src/web/templates/icons` ([Lucide](https://lucide.dev), ISC).

`app.css` and `basecoat.min.js` are committed, so building the Rust app needs no Node.
After changing Tailwind classes in `src/web/templates/` or `styles.css`, rebuild them:

```sh
npm ci
npm test
npm run build
```

CI fails when the committed files are out of date.
